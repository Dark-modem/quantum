## ۴) تصمیم معماری

**الف) کدام پنل کنترلر است؟** ایران (`185.226.119.74`) — طبق طراحی (حساب‌ترافیکی billable و مدیریت متمرکز). باینری پنل ایران از v1.27.1 به build همین شاخه (**v1.28.0**) ارتقا می‌یابد (dispatch `agent`، هاب، bind_host در آن است).

**ب) آیا Agent با پنل کامل روی همان میزبان ایران سازگار است؟** بله — Agent سرویس systemd مستقل است، هیچ listener باز نمی‌کند، فاقد وب‌UI است و مصرف RAM آن در حد چند ده MB است؛ روی 956 MB ایران با 648 MB آزاد مشکلی نیست. (نصاب خودش هشدار «پنل روی همین هاست» می‌دهد که برای تست آزمایشی مجاز است.)

**ج) انتقال امن Agent↔کنترلر بدون دامنه (بند ۴-الف):**
پنل حالت `tls ip` داخلی دارد: CA ده‌سالهٔ محلی + سرتِ خودامضا با **IP داخل SAN** (`panel/tls_ip.go:116-117`). روش صفر-کد:
1. `gre-panel tls ip` (یا API) روی کنترلر → TLS روی 7443 بالا می‌آید.
2. `quantum-ca.crt` را روی **هر دو endpoint** در `/usr/local/share/ca-certificates/quantum-ca.crt` نصب و `update-ca-certificates` اجرا کن.
3. Agentها به `wss://185.226.119.74:7443/<base>/api/agent/ws` وصل می‌شوند؛ تأیید گواهی با CA سیستم پاس می‌شود و **TOFU `tls_pin` هم ذخیره می‌شود** ⇒ شرط GO جلسهٔ ۴ برقرار است.
4. fallback صفر-تغییر برای تست: `ws://:7777` (انحراف مستند از شرط GO — فقط با تأیید مالک).

**د) آیا install-controller.sh لازم است؟** **نه برای تست اول.** nginx/certbot/دامنه لازم نیست؛ پنل فعلی + گزینهٔ الف کافی است. اسکریپت ناقص ماند و بعداً برای استقرار نهایی با دامنه تکمیل می‌شود.

**هـ) تعارض با سرویس‌های موجود؟** هیچ‌کدام از GRE/peer_link، خروجی Xray (443 loopback) و sshd با پورت‌های Matrix تداخل ندارند. تعارض واقعی فقط **پیکربندی Matrix یتیمِ خارج** است (حذف با بکاپ) و **پورت 2020**.

## ۵) ترتیب پیشنهادی استقرار (پیش‌نویس — هنوز اجرا نشده)

0. پیش‌نیاز CI: `go test -race -count=5` روی لینوکس (طبق `docs/INTEGRATION-NOTES.md`).
1. ساخت باینری‌ها از `c9829ce`: `gre-panel-linux-amd64` و `gre-panel-linux-arm64` + `checksums.txt`.
2. بکاپ: `tar -czf ~/gre-panel-backup.tgz /etc/gre-panel` روی هر دو + ذخیرهٔ `iptables-save` و `ss -tulnp`.
3. خارج: بکاپ و سپس **حذف پیکربندی Matrix یتیم** (پنل خارج → Matrix remove؛ یا `matrix.json` + `matrix-tinc/` با توقف unit) → پورت 2020 و instance «matrix» آزاد.
4. ایران: ارتقای باینری به v1.28.0 (`--binary` مسیر install، بدون ریلیز عمومی) → ری‌استارت gre-panel → health OK.
5. فعال‌سازی TLS: `gre-panel tls ip` روی کنترلر → نصب `quantum-ca.crt` در trust سیستم هر دو سرور.
6. ساخت دو توکن یک‌بارمصرف از داشبورد (نقش iran / foreign).
7. خارج: ارتقای باینری به v1.28.0 (arm64) → `install-agent.sh --server https://185.226.119.74:7443/<base> --binary … --token-file …` → تأیید `"connected": true` و `tls_pin` غیرخالی.
8. ایران: `install-agent.sh` مشابه (role=iran) → تأیید اتصال.
9. داشبورد → تب عوامل → هر دو online؛ سپس ساخت تونل Matrix (mesh=0، پورت forward=8443) → وضعیت active.
10. اثبات: `ping -I qmx0` دوطرفه + اتصال واقعی به 8443 از بیرون + چک ترافیک در `/api/agent-tunnels`.
11. تست‌های مقاومتی: توقف gre-panel (۲ دقیقه) → تونل باید بماند؛ `restart gre-agent` → وصل مجدد؛ revoke → kick.
12. حذف و پاک‌سازی: delete تونل از داشبورد → uninstall-agent → مقایسهٔ `iptables-save` و `ss` با گام ۲ (diff فقط-عمدی).
13. ثبت گزارش نتایج (موفق/ناموفق هر گام) در همین سند.
